# Nostr SDK

## Description

Nostr protocol implementation, Relay, RelayPool, high-level client library, NWC client and more.

## Documentation

Learn more at <https://nostrdevkit.org>.

### Supported runtimes

| Runtime      | Supported |
|--------------|-----------|
| Web browsers | ✅        |
| Node.js      | ❌        |
| React Native | ❌        |

Node.js and React Native are available as separate packages:

- `@nostrdevkit/nostr-sdk-node`
- `@nostrdevkit/nostr-sdk-react-native`

Are you interested in another runtime? Open an issue [here](https://github.com/nostrdevkit/nostr-sdk-ffi).

## State

**This library is in an ALPHA state**, things that are implemented generally work but the API will change in breaking ways.
